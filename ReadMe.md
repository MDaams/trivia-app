# Tech stack
Frontend: React (Vite)
Backend Java (Spring boot)

# Run dev
## Start backend
```.\mvnw.cmd spring-boot:run```

## Start frontend
```npm run dev```


# Run specs
## Backend
```.\mvnw clean test```

## Frontend
```npm run test```

# Run staging
## Docker compose
```docker compose up --build```

# Documentation
Can be found in the ```/docs``` directory.
